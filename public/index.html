🔑 Brevo API Key
Saved in your browser only. Never shared with anyone.
How to get your Brevo key (you already have an account ✓):
1. Log in at app.brevo.com
2. Click your name (top right) → SMTP & API
3. Click API Keys tab → Generate a new API key
4. Name it "mGuru" → click Generate
5. Copy the key and paste it above
6. Then go to Senders & Domains → Senders → Add a sender and verify your email
🔌 Backend API URL (after Vercel deploy)
Leave empty if this page IS already deployed on Vercel (it auto-connects)
How to deploy on Vercel (free):
1. Go to github.com → New repo → upload the project zip contents
2. Go to vercel.com → New Project → import your GitHub repo
3. Add environment variable: BREVO_API_KEY = your key
4. Deploy → copy your Vercel URL → paste above
